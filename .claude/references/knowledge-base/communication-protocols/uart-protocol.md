# UART Protocol — 验证指南

UART（Universal Asynchronous Receiver/Transmitter）是最基础的异步串行通信协议，广泛用于调试、诊断、标定和低速外设通信。

## 协议基础

### 帧格式

| 字段 | 长度 | 说明 |
|------|------|------|
| Start Bit | 1 bit | 起始位（低电平） |
| Data Bits | 5~9 bit | 数据位（常用 8 bit） |
| Parity Bit | 0/1 bit | 校验位（奇/偶/无） |
| Stop Bits | 1~2 bit | 停止位（高电平） |

### 波特率
| 波特率 | 应用场景 |
|--------|---------|
| 9600 | 低速调试、GPS |
| 115200 | 标准调试、诊断 |
| 230400 | 高速标定 |
| 921600 | 高速下载 |

### 流控制
| 类型 | 信号 | 说明 |
|------|------|------|
| 无流控 | — | 无硬件流控 |
| RTS/CTS | RTS, CTS | 硬件流控 |
| XON/XOFF | 软件字符 | 软件流控 |

## 关键测试要点

### 1. 基本收发

**测试要点：**
- [ ] 验证发送数据（TX 引脚波形）
- [ ] 验证接收数据（RX 引脚采样）
- [ ] 验证不同波特率（9600 ~ 921600）
- [ ] 验证不同数据位（7/8/9 bit）
- [ ] 验证不同校验位（奇/偶/无）
- [ ] 验证不同停止位（1/1.5/2 bit）

### 2. 波特率误差容忍

**测试要点：**
- [ ] 验证 ±2% 波特率误差（通常要求）
- [ ] 验证 ±3% 波特率误差（极限测试）
- [ ] 验证主从波特率不匹配时的数据错误

### 3. FIFO/DMA

**测试要点：**
- [ ] 验证 TX FIFO（发送缓冲区）
- [ ] 验证 RX FIFO（接收缓冲区）
- [ ] 验证 FIFO 阈值中断（半满/满）
- [ ] 验证 DMA 传输（大批量数据）

### 4. 错误检测

| 错误 | 检测条件 | 测试方法 |
|------|---------|---------|
| Framing Error | 停止位不为 1 | 配置不匹配的停止位 |
| Parity Error | 校验和不匹配 | 注入校验错误 |
| Overrun Error | RX 寄存器未读就被覆盖 | 延迟读取 |
| Noise Error | 采样值不一致 | 注入噪声 |
| Break Error | 持续低电平超过一帧 | 拉低 TX 线 |

### 5. LIN 模式（UART 的 LIN 扩展）

部分 MCU 的 UART 支持 LIN 模式：
- Break 场检测（13+ bit 低电平）
- LIN 同步场检测（0x55）

**测试要点：**
- [ ] 验证 Break 场检测
- [ ] 验证 LIN 同步场检测
- [ ] 验证 LIN 自动波特率校准

## 常见缺陷

1. **波特率不匹配**：主从波特率不同，数据完全错乱
2. **流控未连接**：RTS/CTS 悬空，导致发送/接收阻塞
3. **电平不匹配**：3.3V MCU 连接 5V 设备，导致电平不兼容
4. **地线不稳**：共地不良，导致信号参考电平漂移
5. **FIFO 溢出**：RX 中断未及时处理，数据丢失
