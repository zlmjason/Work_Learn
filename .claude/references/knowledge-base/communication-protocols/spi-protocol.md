# SPI Protocol — 验证指南

SPI（Serial Peripheral Interface）是一种高速全双工同步串行通信协议，广泛用于板级高速外设通信（传感器、Flash、DAC/ADC 等）。

## 协议基础

### 信号线
| 信号 | 方向 | 说明 |
|------|------|------|
| SCLK | 主 → 从 | 时钟 |
| MOSI | 主 → 从 | 主出从入 |
| MISO | 从 → 主 | 主入从出 |
| SS/CS | 主 → 从 | 片选（低有效） |

### 时钟模式（CPOL/CPHA）
| 模式 | CPOL | CPHA | 时钟空闲 | 采样边沿 |
|------|------|------|---------|---------|
| 0 | 0 | 0 | 低 | 上升沿 |
| 1 | 0 | 1 | 低 | 下降沿 |
| 2 | 1 | 0 | 高 | 下降沿 |
| 3 | 1 | 1 | 高 | 上升沿 |

### 帧格式
- 数据位宽：4 ~ 32 bit（可配置）
- 传输方向：MSB 优先 / LSB 优先
- 波特率：最高 F_PCLK/2

## 关键测试要点

### 1. 时钟配置

**测试要点：**
- [ ] 验证 4 种时钟模式（Mode 0/1/2/3）
- [ ] 验证不同波特率（100K ~ F_PCLK/2）
- [ ] 验证时钟极性和相位匹配（主从必须一致）
- [ ] 验证时钟分频器（/2, /4, /8, /16...）

### 2. 片选控制

**测试要点：**
- [ ] 验证硬件片选（自动在传输期间拉低）
- [ ] 验证软件片选（手动控制 GPIO）
- [ ] 验证片选极性（低有效 / 高有效）
- [ ] 验证多从机切换（多个 CS 信号）

### 3. 数据传输

**测试要点：**
- [ ] 验证全双工传输（同时发送和接收）
- [ ] 验证不同数据位宽（8/16/32 bit）
- [ ] 验证 MSB/LSB 优先
- [ ] 验证连续传输（TXE/RXNE 标志）
- [ ] 验证 DMA 传输（大批量数据）

### 4. 错误检测

| 错误 | 说明 | 测试方法 |
|------|------|---------|
| Overrun | 新数据到达但旧数据未读 | 延迟读取 DR |
| Mode Fault | 多主冲突 | 另一主节点同时激活 |
| CRC Error | CRC 校验失败 | 注入 CRC 错误 |
| Frame Error | 帧格式错误 | 配置不匹配的数据位宽 |

## 常见缺陷

1. **时钟模式不匹配**：主从 CPOL/CPHA 配置不同，导致数据错乱
2. **片选释放过早**：传输未完成就释放 CS，从机丢弃数据
3. **溢出未处理**：RXNE 标志未清除，导致 Overrun
4. **DMA 配置错误**：DMA 传输长度与 SPI 数据量不匹配
