# FlexRay Protocol — 验证指南

FlexRay 是一种高速确定性通信协议，主要用于底盘线控制动、线控转向等对实时性要求极高的系统。

## 协议基础

### 物理层
- 双通道（Channel A / Channel B）
- 波特率：10 Mbps（固定）
- 拓扑：总线型、星型、混合型
- 线缆：屏蔽双绞线
- 终端电阻：100Ω（每通道两端）

### 通信周期（Communication Cycle）

| 段 | 长度 | 说明 |
|----|------|------|
| 静态段（Static Segment） | 固定时隙 | 确定性通信，TDMA |
| 动态段（Dynamic Segment） | 事件触发 | 按需发送，mini-slotting |
| 符号窗口（Symbol Window） | 固定 | 网络空闲符号 |
| 网络空闲时间（NIT） | 固定 | 时钟同步 |

### 帧格式

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧头（Header） | 5 bytes | 标志位、长度、CRC |
| 负载（Payload） | 0~254 bytes | 数据 |
| 帧尾（Trailer） | 3 bytes | CRC |

## 关键测试要点

### 1. 静态段 TDMA

**时隙分配：**
- 每个节点在固定时隙发送
- 时隙长度：1~15 MT（Macrotick）
- 最大时隙数：1023

**测试要点：**
- [ ] 验证各节点在分配的时隙发送
- [ ] 验证时隙边界（不跨越时隙边界）
- [ ] 验证静态段最大利用率
- [ ] 验证时钟同步（NIT 中的同步帧）

### 2. 动态段 Mini-Slotting

**测试要点：**
- [ ] 验证动态帧在 mini-slot 内发送
- [ ] 验证优先级（ID 小的优先）
- [ ] 验证动态段溢出（低优先级帧被截断）
- [ ] 验证动态段到静态段的过渡

### 3. 时钟同步

**测试要点：**
- [ ] 验证同步帧的发送和接收
- [ ] 验证时钟漂移补偿
- [ ] 验证冷启动（无参考时钟时启动）
- [ ] 验证时钟失效容错（单通道失效）

### 4. 双通道冗余

**测试要点：**
- [ ] 验证双通道同时工作
- [ ] 验证单通道失效（另一通道继续工作）
- [ ] 验证通道切换（失效后切换到另一通道）

## 常见缺陷

1. **时隙配置冲突**：两个节点分配到同一时隙，导致数据冲突
2. **时钟不同步**：时钟漂移未补偿，导致帧丢失
3. **冷启动失败**：没有同步节点，网络无法启动
4. **动态段溢出**：低优先级事件帧总是被截断
