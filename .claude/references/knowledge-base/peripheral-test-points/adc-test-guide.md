# ADC — 测试验证指南

ADC（Analog-to-Digital Converter）是 MCU 的关键模拟外设，用于将模拟信号转换为数字量，广泛应用于传感器采集、电池监测、温度检测等场景。

## 功能特性

### 1. 基本转换

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 分辨率 | 12/16 bit | 有效位数 |
| 采样率 | 1 MSPS ~ 5 MSPS | 每秒采样次数 |
| 输入范围 | 0 ~ VREF+ | 单端输入范围 |

**测试要点：**
- [ ] 验证单通道单次转换（Single Mode）
- [ ] 验证单通道连续转换（Continuous Mode）
- [ ] 验证扫描模式（多通道顺序转换）
- [ ] 转换时间 = 采样时间 + 逐次逼近时间（12.5 cycles）
- [ ] 验证 EOC（End of Conversion）标志
- [ ] 验证数据对齐（左对齐 / 右对齐）

### 2. 触发源

| 触发源 | 说明 |
|--------|------|
| 软件触发 | 写寄存器启动 |
| 定时器触发 | TRGO 事件 |
| 外部引脚 | EXTI 触发 |

**测试要点：**
- [ ] 验证软件触发转换
- [ ] 验证定时器触发（TIMx_TRGO）
- [ ] 验证外部引脚触发
- [ ] 验证触发极性（上升沿/下降沿）
- [ ] 验证触发延迟（从触发到开始采样的时间）

### 3. 采样时间与输入阻抗

**测试要点：**
- [ ] 验证最小采样时间（高速信号）
- [ ] 验证最大采样时间（高阻抗信号源）
- [ ] 验证采样时间计算：T_s ≥ (R_adc + R_source) × C_adc × ln(2^(N+2))
- [ ] 验证不同采样周期（3/15/28/56/84/112/144/480 cycles）

### 4. 多通道与序列

**测试要点：**
- [ ] 验证规则组（Regular Group）序列转换
- [ ] 验证注入组（Injected Group）优先级转换
- [ ] 验证规则组 + 注入组同时工作
- [ ] 验证 DMA 传输（规则组结果自动搬运）
- [ ] 验证通道间串扰（前一通道影响后一通道）

### 5. 高级功能

**测试要点：**
- [ ] 验证模拟看门狗（AWD，超出阈值触发中断）
- [ ] 验证温度传感器通道
- [ ] 验证内部参考电压（VREFINT）
- [ ] 验证电池监测通道（VBAT）
- [ ] 验证过采样（Oversampling，提高有效分辨率）
- [ ] 验证校准（Offset/Linearity Calibration）
- [ ] 验证双 ADC 模式（同步/交错/交替触发）
- [ ] 验证三重 ADC 交错模式

## 精度测试

| 参数 | 测试方法 | 典型值 |
|------|---------|--------|
| INL（积分非线性） | 斜坡输入 | ±2 LSB |
| DNL（微分非线性） | 斜坡输入 | ±1 LSB |
| Offset（偏移误差） | 输入接地 | ±3 LSB |
| Gain（增益误差） | 输入满量程 | ±5 LSB |
| ENOB（有效位数） | FFT 分析 | 10.5 bit（12-bit ADC） |
| SNR（信噪比） | 正弦波输入 | 60 dB |

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| 输入电压 | 0V | 转换结果 = 0 |
| 输入电压 | VREF+ | 转换结果 = 0xFFF（12-bit） |
| 输入电压 | VREF+ + 0.1V | 钳位到 0xFFF |
| 输入电压 | -0.1V | 钳位到 0x000 |
| 采样率 | 最大 | 不丢失采样 |
| 采样时间 | 最小（3 cycles） | 适用于低阻抗源 |
| 温度 | 125°C | 精度满足规格 |
| 温度 | -40°C | 精度满足规格 |

## 常见缺陷

1. **采样时间不足**：高阻抗源未充电到稳定值，导致精度差
2. **输入电压超限**：超过 VREF+ 或低于 VSSA，可能损坏芯片
3. **DMA 配置错误**：DMA 缓冲区大小与序列长度不匹配
4. **校准未执行**：未做 Offset/Linearity 校准，精度下降
5. **参考电压不稳**：VREF+ 波动导致全量程漂移
6. **通道串扰**：多通道快速切换时前一通道电荷注入后一通道
7. **注入组抢占**：注入组打断规则组导致规则组数据不连续
