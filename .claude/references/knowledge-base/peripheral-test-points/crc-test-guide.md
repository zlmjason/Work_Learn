# CRC — 测试验证指南

CRC（Cyclic Redundancy Check）是 MCU 的硬件加速校验单元，用于快速计算数据的 CRC 值，广泛应用于通信校验、Flash 校验、数据完整性验证等场景。

## 功能特性

### 1. 基本 CRC 计算

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 多项式 | 可配置 | CRC-32 / CRC-16 / CRC-8 等 |
| 输入数据 | 8/16/32 bit | 字节/半字/字 |
| 初始值 | 可配置 | 全 0 / 全 1 / 自定义 |

**测试要点：**
- [ ] 验证 32 bit 输入 CRC 计算
- [ ] 验证 16 bit 输入 CRC 计算
- [ ] 验证 8 bit 输入 CRC 计算
- [ ] 验证默认多项式（CRC-32：0x4C11DB7）
- [ ] 验证自定义多项式（可编程 CRC）
- [ ] 验证默认初始值（全 1）
- [ ] 验证自定义初始值
- [ ] 验证 CRC 计算结果与软件算法一致性

### 2. 常用 CRC 标准

| 标准 | 多项式 | 初始值 | 输入/输出反转 | 最终异或 |
|------|--------|--------|-------------|---------|
| CRC-32 | 0x04C11DB7 | 0xFFFFFFFF | 是 | 0xFFFFFFFF |
| CRC-32/MPEG-2 | 0x04C11DB7 | 0xFFFFFFFF | 否 | 0x00000000 |
| CRC-16-CCITT | 0x00001021 | 0x0000FFFF | 否 | 0x00000000 |
| CRC-16-IBM | 0x00008005 | 0x00000000 | 是 | 0x00000000 |
| CRC-8 | 0x00000007 | 0x00000000 | 否 | 0x00000000 |

**测试要点：**
- [ ] 验证 CRC-32 标准计算
- [ ] 验证 CRC-32/MPEG-2 标准计算
- [ ] 验证 CRC-16-CCITT 标准计算
- [ ] 验证 CRC-16-IBM 标准计算
- [ ] 验证 CRC-8 标准计算
- [ ] 验证已知测试向量（如 "123456789" 的 CRC 值）

### 3. 输入/输出数据配置

**测试要点：**
- [ ] 验证输入数据反转（RefIn，按位反转）
- [ ] 验证输出数据反转（RefOut）
- [ ] 验证输入字节序（大端/小端）
- [ ] 验证输出最终异或值（Final XOR）
- [ ] 验证输入数据大小无关性（任意长度字节）

### 4. DMA 模式

**测试要点：**
- [ ] 验证 DMA 传输 CRC（大批量数据自动计算）
- [ ] 验证 DMA 传输后 CRC 结果读取
- [ ] 验证 DMA 循环模式 CRC
- [ ] 验证 CRC + DMA 计算时间

## 精度与性能测试

| 测试项 | 方法 | 预期结果 |
|--------|------|---------|
| 计算正确性 | 与软件 CRC32 库对比 | 结果一致 |
| 单字计算时间 | 测量 32-bit 输入 | 1 个 AHB 时钟 |
| 大数据块计算 | DMA 1KB 数据 | 线性时间，无误差 |
| 边界条件 | 0 字节输入 | 初始值输出 |
| 边界条件 | 1 字节输入 | 正确计算 |
| 边界条件 | 奇数长度输入 | 正确计算 |

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| 输入数据 | 0x00000000 | 按 0 计算 |
| 输入数据 | 0xFFFFFFFF | 按全 1 计算 |
| 数据长度 | 0 字节 | 输出 = 初始值 |
| 数据长度 | 1 字节 | 正确 CRC |
| 数据长度 | 最大（无限制） | 正确 CRC |
| 多项式 | 0x00000001 | 最小多项式 |
| 初始值 | 0x00000000 | 从 0 开始 |
| 初始值 | 0xFFFFFFFF | 从全 1 开始 |

## 常见缺陷

1. **多项式配置错误**：可编程 CRC 的多项式位宽与实现不一致
2. **初始值未设置**：未写入初始值，使用默认值不符合预期
3. **输入反转未配置**：RefIn 与协议要求不一致
4. **输出反转未配置**：RefOut 与协议要求不一致
5. **最终异或值遗漏**：未做 Final XOR，结果偏差
6. **字节序错误**：大端/小端配置与数据实际字节序不符
7. **CRC 寄存器未复位**：连续计算时未重置，结果累积
8. **DMA 传输后未等待**：DMA 未完成就读取 CRC，结果错误
