# DMA — 测试验证指南

DMA（Direct Memory Access）是 MCU 中实现外设与内存之间高速数据传输的关键模块，无需 CPU 干预，极大提升数据吞吐效率。

## 功能特性

### 1. 基本传输

| 参数 | 说明 |
|------|------|
| 传输方向 | 外设→内存 / 内存→外设 / 内存→内存 |
| 数据宽度 | 8/16/32 bit |
| 传输模式 | 单次 / 循环（Circular） |
| 地址模式 | 固定 / 递增 |

**测试要点：**
- [ ] 验证外设→内存传输（如 ADC 结果搬运）
- [ ] 验证内存→外设传输（如 DAC/ UART TX）
- [ ] 验证内存→内存传输（如 Flash 编程缓冲区拷贝）
- [ ] 验证字节传输（8 bit）
- [ ] 验证半字传输（16 bit）
- [ ] 验证字传输（32 bit）
- [ ] 验证源地址递增 vs 固定
- [ ] 验证目标地址递增 vs 固定
- [ ] 验证单次传输（Normal Mode）
- [ ] 验证循环传输（Circular Mode，自动重载）

### 2. FIFO 与突发传输（仅 DMA2/FIFO-enabled DMA）

**测试要点：**
- [ ] 验证 FIFO 模式（4 字深度）
- [ ] 验证 FIFO 阈值（1/2/3/4 字触发）
- [ ] 验证单次突发（Single Burst）
- [ ] 验证 4-beat 突发（INCR4）
- [ ] 验证 8-beat 突发（INCR8）
- [ ] 验证 16-beat 突发（INCR16）
- [ ] 验证 FIFO 错误（欠载/溢出）

### 3. 优先级与仲裁

**测试要点：**
- [ ] 验证通道优先级（Low / Medium / High / Very High）
- [ ] 验证多通道同时请求时的仲裁
- [ ] 验证固定优先级 vs 轮询优先级
- [ ] 验证高优先级通道抢占低优先级

### 4. 中断与事件

**测试要点：**
- [ ] 验证半传输中断（HTIF）
- [ ] 验证传输完成中断（TCIF）
- [ ] 验证传输错误中断（TEIF）
- [ ] 验证直接模式错误（DMEIF，FIFO 模式）
- [ ] 验证 FIFO 错误中断（FEIF）
- [ ] 验证中断标志清除

### 5. 双缓冲模式

**测试要点：**
- [ ] 验证双缓冲区切换
- [ ] 验证当前使用缓冲区指示
- [ ] 验证 DMA 正在传输时切换缓冲区
- [ ] 验证双缓冲在 ADC 连续采集中的应用

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| 传输数量 | 1（最小） | 单字节/字传输正确 |
| 传输数量 | 最大（65535） | 大容量传输正确 |
| 地址对齐 | 字节对齐（8 bit） | 无对齐限制 |
| 地址对齐 | 字对齐（32 bit） | 最高效传输 |
| 地址对齐 | 非对齐（32 bit 传输在奇地址） | 验证是否支持/报错 |
| FIFO 阈值 | 1/4 Full | 正常触发 |
| FIFO 阈值 | Full | 正常触发 |
| 突发大小 | 超过 FIFO 阈值 | 报错或异常 |

## Cache 一致性（带 Cache 的 MCU）

**测试要点：**
- [ ] 验证 DMA 写入内存后 CPU 读取（Cache Invalidate）
- [ ] 验证 CPU 写入内存后 DMA 读取（Cache Clean）
- [ ] 验证 DMA 缓冲区位于 Non-cacheable 区域
- [ ] 验证 SCB_InvalidateDCache_by_Addr() 调用
- [ ] 验证 SCB_CleanDCache_by_Addr() 调用

## 常见缺陷

1. **传输方向配置错误**：外设→内存 配成 内存→外设
2. **地址未递增**：连续传输但地址固定，只覆盖同一位置
3. **数据宽度不匹配**：DMA 16 bit 但外设 8 bit，数据错乱
4. **循环模式未使能**：单次传输后停止，未持续采集
5. **中断未清除**：中断标志未清，导致连续进入 ISR
6. **Cache 不一致**：DMA 写入但 CPU 读取到旧 Cache 数据
7. **FIFO 配置错误**：突发大小超过 FIFO 深度，导致错误
8. **通道冲突**：两个外设同时使用同一 DMA 通道
