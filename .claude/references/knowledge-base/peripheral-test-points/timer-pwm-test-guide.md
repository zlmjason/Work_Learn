# Timer/PWM — 测试验证指南

Timer 是 MCU 最核心的外设之一，用于定时、计数、PWM 输出、输入捕获、编码器接口等。Timer 的精度直接影响系统时基和电机控制等关键功能。

## 功能特性

### 1. 基本定时

| 模式 | 说明 |
|------|------|
| 向上计数 | 从 0 计数到 ARR，然后溢出 |
| 向下计数 | 从 ARR 计数到 0，然后溢出 |
| 中心对齐 | 向上计数到 ARR-1，再向下计数到 1 |

**测试要点：**
- [ ] 验证向上计数（CNT 从 0 递增到 ARR）
- [ ] 验证向下计数（CNT 从 ARR 递减到 0）
- [ ] 验证中心对齐模式（先上后下，溢出事件在中心）
- [ ] 验证计数器周期 = (ARR + 1) × (PSC + 1) / fCLK
- [ ] 验证预分频器（PSC）实时更新（影子寄存器）
- [ ] 验证自动重载（ARR）实时更新（影子寄存器）
- [ ] 验证计数器使能/禁用（CEN 位）

### 2. PWM 输出

| 模式 | 说明 |
|------|------|
| PWM Mode 1 | 向上计数时 CNT < CCR 为有效电平 |
| PWM Mode 2 | 向上计数时 CNT ≥ CCR 为有效电平 |

**测试要点：**
- [ ] 验证 PWM Mode 1 波形（占空比 = CCR / (ARR + 1)）
- [ ] 验证 PWM Mode 2 波形（反向极性）
- [ ] 验证 PWM 频率精度（示波器测量 vs 理论值）
- [ ] 验证占空比 0%（CCR = 0）
- [ ] 验证占空比 100%（CCR = ARR + 1）
- [ ] 验证输出极性（Active High / Active Low）
- [ ] 验证互补 PWM 输出（带死区）
- [ ] 验证死区时间精度（DTG 配置 vs 实际测量）
- [ ] 验证刹车（Break）输入强制 PWM 到安全状态

### 3. 输入捕获

**测试要点：**
- [ ] 验证上升沿捕获（IC1/IC2/IC3/IC4）
- [ ] 验证下降沿捕获
- [ ] 验证双边沿捕获
- [ ] 验证输入滤波（不同滤波宽度）
- [ ] 验证输入分频（每 N 个边沿捕获一次）
- [ ] 验证捕获值读取（CCR 寄存器）
- [ ] 验证捕获溢出（两次捕获之间计数器溢出）
- [ ] 验证 PWM 输入模式（频率 + 占空比同时测量）

### 4. 编码器接口

**测试要点：**
- [ ] 验证 TI1 计数模式（单通道）
- [ ] 验证 TI1+TI2 计数模式（正交编码器）
- [ ] 验证正转（TI1 超前 TI2 90°）
- [ ] 验证反转（TI2 超前 TI1 90°）
- [ ] 验证编码器索引信号清零（Z 相信号）
- [ ] 验证计数器溢出/下溢

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| 计数器周期 | ARR = 0 | 每 1 个时钟溢出 |
| 计数器周期 | ARR = 0xFFFF | 最大周期 |
| PWM 占空比 | CCR = 0 | 0% 占空比 |
| PWM 占空比 | CCR = ARR | 接近 100% |
| PWM 频率 | 最高频率（fCLK/2） | 波形正常 |
| PWM 频率 | 最低频率 | 波形正常 |
| 死区时间 | DT = 0 | 无死区 |
| 死区时间 | DT = 最大值 | 最大死区 |
| 捕获频率 | 超过计数器时钟 | 丢失捕获 |

## 常见缺陷

1. **影子寄存器未更新**：写入 ARR/PSC 但未触发更新事件，新值未生效
2. **PWM 极性配置错误**：Mode 1 和 Mode 2 混淆，导致输出反向
3. **死区时间不足**：半桥驱动时上下管同时导通，炸管
4. **刹车信号未处理**：异常时未将 PWM 强制到安全状态
5. **捕获中断延迟**：ISR 响应慢，错过下一次捕获
6. **计数器溢出未处理**：编码器高速运行时溢出导致位置计算错误
