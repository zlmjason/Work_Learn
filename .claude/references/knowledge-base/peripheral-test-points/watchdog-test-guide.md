# Watchdog — 测试验证指南

Watchdog（看门狗）是 MCU 的关键安全外设，用于检测和恢复系统异常（程序跑飞、死循环、死锁等），是功能安全（ASIL）系统必不可少的模块。

## 功能特性

### 1. 独立看门狗（IWDG）

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 时钟源 | LSI（低速内部 RC） | 独立于主时钟 |
| 超时范围 | 0.1 ms ~ 32 s | 取决于预分频和重载值 |
| 启动方式 | 软件 / 硬件（选项字节） | 硬件启动不可禁用 |

**测试要点：**
- [ ] 验证软件启动 IWDG
- [ ] 验证硬件启动 IWDG（选项字节配置）
- [ ] 验证正常喂狗（在超时前刷新）
- [ ] 验证超时复位（未喂狗触发复位）
- [ ] 验证超时时间计算：Timeout = (Reload + 1) × Prescaler / LSI_Freq
- [ ] 验证预分频器配置（/4 /8 /16 /32 /64 /128 /256）
- [ ] 验证窗口模式（Window Watchdog，必须在窗口内喂狗）
- [ ] 验证窗口上下限边界（窗口内/窗口上沿/窗口下沿）
- [ ] 验证写保护（KR 寄存器解锁序列）
- [ ] 验证在 Stop/Standby 模式下的行为

### 2. 窗口看门狗（WWDG）

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 时钟源 | PCLK1 / 4096 | 来自主时钟 |
| 超时范围 | ~1 ms ~ ~58 ms | 取决于时钟分频 |
| 窗口机制 | 可配置 | 只能在窗口内喂狗 |

**测试要点：**
- [ ] 验证 WWDG 启动
- [ ] 验证正常喂狗（在窗口内刷新）
- [ ] 验证提前喂狗（在窗口外刷新 → 复位）
- [ ] 验证超时复位（未喂狗 → 复位）
- [ ] 验证提前唤醒中断（EWI，在复位前触发中断）
- [ ] 验证预分频器（/1 /2 /4 /8）
- [ ] 验证窗口值配置（上窗口边界）
- [ ] 验证计数器下边界（固定 0x40）
- [ ] 验证 T6 位（必须在刷新时保持为 1）

### 3. 复位检测

**测试要点：**
- [ ] 验证 IWDG 复位后 RCC_CSR 标志
- [ ] 验证 WWDG 复位后 RCC_CSR 标志
- [ ] 验证软件清除复位标志
- [ ] 验证复位标志在系统启动时的读取

## 安全相关测试

| 场景 | 测试方法 | 预期结果 |
|------|---------|---------|
| 主循环卡死 | 在循环中禁止中断并死等 | IWDG 超时复位 |
| 中断死循环 | ISR 中无限循环 | IWDG 超时复位 |
| 低优先级任务饿死 | 高优先级任务占满 CPU | IWDG 超时复位 |
| 时钟失效 | 主时钟停振 | IWDG 仍工作（LSI 独立） |
| 喂狗过早 | WWDG 窗口外刷新 | WWDG 复位 |
| 喂狗过晚 | 超过超时时间 | 看门狗复位 |

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| IWDG 重载值 | 0x000 | 最短超时 |
| IWDG 重载值 | 0xFFF | 最长超时 |
| WWDG 计数器 | 0x40 | 马上超时（T6=0 立即复位） |
| WWDG 窗口 | 0x7F | 最大窗口 |
| WWDG 窗口 | 0x40 | 仅允许在 0x40 喂狗 |
| 喂狗周期 | 刚好在超时前 | 正常 |
| 喂狗周期 | 刚好超时后 | 复位 |

## 常见缺陷

1. **喂狗位置不当**：在中断中喂狗，主循环卡死无法检测
2. **窗口配置错误**：WWDG 窗口太窄，正常流程来不及喂狗
3. **时钟校准未做**：LSI 频率偏差大，实际超时时间与预期不符
4. **喂狗周期估算错误**：未考虑最坏情况执行时间
5. **复位源未区分**：多种复位源共用同一处理逻辑
6. **调试时看门狗干扰**：调试期间未暂停看门狗，导致调试复位
7. **低功耗模式未处理**：进入 Stop 模式后看门狗继续计数导致意外复位
