# Crypto（密码学加速）— 测试验证指南

Crypto 引擎是高端车规 MCU 的关键安全外设，提供硬件加速的 AES、DES、HASH、RSA、ECC、TRNG 等密码学运算，用于安全启动、加密通信、密钥存储等功能。

## 功能特性

### 1. AES 加解密

| 模式 | 说明 |
|------|------|
| ECB | 电子密码本（不推荐） |
| CBC | 密码分组链接 |
| CTR | 计数器模式 |
| GCM | 伽罗瓦计数器模式（带认证） |
| CCM | 计数器 with CBC-MAC |
| CFB | 密文反馈 |
| OFB | 输出反馈 |

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| AES 数据 | 0 字节 | 按空消息处理 |
| AES 数据 | 15 字节（非对齐） | 按 Padding 处理 |
| AES 数据 | 16 字节（1 block） | 正常加密 |
| AES 密钥 | 全 0 | 正常计算 |
| AES IV | 全 0 | 正常计算（CBC/CTR） |
| HASH | 0 字节 | 空消息 HASH 值 |
| HASH | 55 字节（刚好 1 block） | 正确 |
| HASH | 56 字节（跨 block） | 正确 |
| HASH | 1MB | 正确 |
| TRNG | 连续读取 | 无重复 |

## 安全测试

| 测试项 | 方法 | 预期结果 |
|--------|------|---------|
| 密钥泄露 | 尝试读取 Key Register | 读取为 0 或报错 |
| 侧信道攻击 | 功耗分析 | 硬件实现有掩码保护 |
| 故障注入 | 电压/时钟毛刺 | 检测并进入安全状态 |
| 缓冲区溢出 | 超长输入 | 截断或报错 |
| 时序攻击 | 固定时间 vs 变时间 | 算法执行时间恒定 |

## 常见缺陷

1. **AES 模式选择错误**：用 ECB 加密大量数据，安全性差
2. **IV 重复使用**：CTR/GCM 模式 IV 重复导致密钥流重用
3. **密钥未擦除**：使用后未安全清除，残留内存中
4. **HASH 碰撞未处理**：攻击者构造碰撞数据
5. **TRNG 熵不足**：在启动早期 TRNG 未充分熵化就使用
6. **安全启动跳过**：调试模式或特定引脚电平跳过验证
7. **密钥权限错误**：低权限代码访问高权限密钥
8. **DMA 安全隔离**：加密 DMA 与普通 DMA 未隔离
