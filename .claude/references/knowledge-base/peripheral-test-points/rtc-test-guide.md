# RTC — 测试验证指南

RTC（Real-Time Clock）是 MCU 的低功耗时钟模块，用于在系统休眠时维持时间计数，是汽车电子中事件时间戳、定时唤醒等功能的基础。

## 功能特性

### 1. 时钟源与校准

| 时钟源 | 典型频率 | 说明 |
|--------|---------|------|
| LSE | 32.768 kHz | 外部晶振，精度最高 |
| LSI | ~32 kHz | 内部 RC，精度较差 |
| HSE / 128 | 取决于 HSE | 外部高速晶振分频 |

**测试要点：**
- [ ] 验证 LSE 时钟源（32.768 kHz 晶振）
- [ ] 验证 LSI 时钟源（内部 RC）
- [ ] 验证 HSE/128 时钟源
- [ ] 验证时钟源切换（运行时切换）
- [ ] 验证数字校准（Digital Calibration，平滑校准）
- [ ] 验证粗校准（Coarse Calibration）
- [ ] 验证校准值计算：Calib = (目标频率 - 实际频率) / 实际频率 × 10^6 ppm
- [ ] 验证校准后日误差（< ±1 s/day @ LSE）
- [ ] 验证参考时钟检测（REFCKON，检测外部 50/60 Hz）

### 2. 时间与日历

**测试要点：**
- [ ] 验证时间设置（时:分:秒）
- [ ] 验证日期设置（年-月-日-星期）
- [ ] 验证 12 小时制 / 24 小时制
- [ ] 验证闰年判断（2月29日）
- [ ] 验证世纪溢出（从 99 → 00 年）
- [ ] 验证夏令时切换（BKP 位）
- [ ] 验证时间读取原子性（避免读取时进位）
- [ ] 验证影子寄存器同步

### 3. 闹钟

**测试要点：**
- [ ] 验证 Alarm A（闹钟 A）
- [ ] 验证 Alarm B（闹钟 B）
- [ ] 验证闹钟匹配（秒/分/时/日/星期/月掩码）
- [ ] 验证闹钟中断
- [ ] 验证闹钟作为唤醒源（从 Stop/Standby 唤醒）
- [ ] 验证闹钟掩码（忽略某些字段匹配）
- [ ] 验证闹钟重复（每秒/每分/每小时/每天/每周/每月）

### 4. 周期性唤醒

**测试要点：**
- [ ] 验证 Wakeup Timer 配置
- [ ] 验证唤醒周期计算：Period = (WUT + 1) / (RTCCLK / WUCKSEL)
- [ ] 验证最小唤醒周期（1 clock）
- [ ] 验证最大唤醒周期（0xFFFF clocks）
- [ ] 验证唤醒中断
- [ ] 验证唤醒从 Standby 模式
- [ ] 验证唤醒从 Stop 模式

### 5. 时间戳

**测试要点：**
- [ ] 验证外部时间戳触发（Tamper 引脚）
- [ ] 验证时间戳记录（保存触发时刻的日期时间）
- [ ] 验证时间戳中断
- [ ] 验证时间戳溢出处理

### 6. 侵入检测（Tamper）

**测试要点：**
- [ ] 验证 Tamper 引脚上升沿检测
- [ ] 验证 Tamper 引脚下降沿检测
- [ ] 验证 Tamper 事件清除备份寄存器
- [ ] 验证 Tamper 中断
- [ ] 验证内部 Tamper（温度/电压监控）
- [ ] 验证主动 Tamper 输出（Active Tamper）

### 7. 备份寄存器

**测试要点：**
- [ ] 验证备份寄存器读写（RTC_BKPxR）
- [ ] 验证备份寄存器在 Standby 模式保持
- [ ] 验证备份寄存器在 VBAT 供电下保持
- [ ] 验证备份域复位（不影响主域）

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| 时间 | 23:59:59 → 00:00:00 | 正确进位，日期+1 |
| 日期 | 12-31 → 01-01 | 正确进位，年+1 |
| 闰年 | 2月28日 → 2月29日 | 正确识别闰年 |
| 非闰年 | 2月28日 → 3月1日 | 正确跳过2月29日 |
| 校准 | +511 ppm（最大正校准） | 频率提升 |
| 校准 | -512 ppm（最大负校准） | 频率降低 |
| 唤醒周期 | 1 RTCCLK | 最短唤醒 |
| 唤醒周期 | 0xFFFF RTCCLK | 最长唤醒 |

## 低功耗测试

| 模式 | 测试要点 |
|------|---------|
| Run | RTC 正常计数，功耗最高 |
| Sleep | RTC 正常计数，CPU 暂停 |
| Stop | RTC 维持计数，可闹钟/唤醒定时器唤醒 |
| Standby | RTC 可选维持，VBAT 供电时保持 |

## 常见缺陷

1. **LSE 启动失败**：晶振未起振或负载电容不匹配
2. **时间读取非原子**：读取时发生秒进位，读到不一致值
3. **影子寄存器不同步**：未等待 RSF 标志就读取
4. **校准值计算错误**：ppm 计算反了，越校准越差
5. **闹钟掩码配置错误**：匹配条件过于严格或宽松
6. **备份域未复位**：首次使用未初始化备份寄存器
7. **VBAT 未接**：Standby 模式下 RTC 和备份寄存器丢失
8. **唤醒周期估算错误**：WUCKSEL 分频未考虑，周期偏差大
