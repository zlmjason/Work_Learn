# GPIO（通用输入输出）— 测试验证指南

GPIO 是 MCU 最基础的外设，所有芯片验证都是从 GPIO 开始的。GPIO 的正确性直接影响后续所有外设和系统功能的验证。

## 功能特性

### 1. 输入模式

| 模式 | 上拉/下拉 | 说明 |
|------|----------|------|
| 浮空输入 | 无 | 高阻态，外部必须驱动 |
| 上拉输入 | 上拉电阻 | 默认高电平 |
| 下拉输入 | 下拉电阻 | 默认低电平 |
| 模拟输入 | 无 | 连接到 ADC/DAC |

**测试要点：**
- [ ] 验证浮空输入（外部不接时读取值不确定）
- [ ] 验证上拉输入（外部不接时读取为 1）
- [ ] 验证下拉输入（外部不接时读取为 0）
- [ ] 验证输入电平阈值（VIH/VIL）
- [ ] 验证输入施密特触发器（迟滞特性）
- [ ] 验证输入速度/带宽限制（高速输入 vs 低速输入）

### 2. 输出模式

| 模式 | 驱动能力 | 说明 |
|------|---------|------|
| 推挽输出 | 强驱动 | 可输出高/低，驱动电流大 |
| 开漏输出 | 低驱动 | 只能输出低或高阻，需外部上拉 |

**测试要点：**
- [ ] 验证推挽输出高电平（VOH）
- [ ] 验证推挽输出低电平（VOL）
- [ ] 验证开漏输出低电平
- [ ] 验证开漏输出高阻态（外部上拉后读取为高）
- [ ] 验证输出速度（Low / Medium / High / Very High）
- [ ] 验证输出驱动电流（Source/Sink 能力）

### 3. 复用功能（Alternate Function）

GPIO 引脚可复用为外设功能：UART_TX/RX、SPI_MOSI/MISO、CAN_TX/RX、I2C_SCL/SDA 等。

**测试要点：**
- [ ] 验证复用功能选择（AF0 ~ AF15）
- [ ] 验证复用功能切换（动态切换 GPIO ↔ AF）
- [ ] 验证复用功能的引脚映射（不同封装引脚映射不同）
- [ ] 验证复用功能的输出驱动能力

### 4. 外部中断（EXTI）

**测试要点：**
- [ ] 验证上升沿触发
- [ ] 验证下降沿触发
- [ ] 验证双边沿触发
- [ ] 验证中断屏蔽（不使能时不触发）
- [ ] 验证中断清除（清除后不再触发）
- [ ] 验证中断优先级
- [ ] 验证 EXTI 作为低功耗唤醒源

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| 输入电平 | VIL_MAX | 读取为 0 |
| 输入电平 | VIH_MIN | 读取为 1 |
| 输出电流 | IOL_MAX | VOL ≤ VOL_MAX |
| 输出电流 | IOH_MAX | VOH ≥ VOH_MIN |
| 翻转速度 | 最高频率 | 波形不畸变 |
| 同时翻转 | 多个 GPIO | 无串扰 |

## 常见缺陷

1. **未配置时钟**：GPIO 时钟未使能就访问寄存器，导致总线挂死
2. **输入浮空**：未配置上拉/下拉，读取值随机跳变
3. **输出冲突**：两个 GPIO 配置为输出且驱动相反电平，形成短路
4. **复用未切换**：外设已使能但 GPIO 未切换到 AF 模式，信号无法输出
5. **中断未清除**：ISR 中未清除中断标志，导致连续触发
