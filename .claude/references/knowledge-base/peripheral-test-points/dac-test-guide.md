# DAC — 测试验证指南

DAC（Digital-to-Analog Converter）将数字量转换为模拟电压输出，用于波形生成、偏置电压设置、模拟控制等场景。

## 功能特性

### 1. 基本输出

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 分辨率 | 12 bit | 有效位数 |
| 输出范围 | 0 ~ VREF+ | 单端输出 |
| 输出缓冲 | 可配置 | 带缓冲驱动能力更强 |

**测试要点：**
- [ ] 验证单通道输出（DAC1/DAC2）
- [ ] 验证双通道独立输出
- [ ] 验证双通道同时输出
- [ ] 验证输出使能/禁用
- [ ] 验证输出缓冲使能/禁用（输出阻抗不同）
- [ ] 验证数据寄存器写入 → 输出电压建立

### 2. 触发源

**测试要点：**
- [ ] 验证软件触发（写入寄存器立即更新）
- [ ] 验证定时器触发（TIMx_TRGO，用于波形生成）
- [ ] 验证外部触发（EXTI）
- [ ] 验证触发极性选择
- [ ] 验证触发后的输出建立时间

### 3. 波形生成

| 模式 | 说明 |
|------|------|
| 噪声生成 | LFSR 伪随机噪声 |
| 三角波生成 | 自动递增/递减 |

**测试要点：**
- [ ] 验证噪声波形（LFSR 掩码可配置）
- [ ] 验证三角波波形（幅值和频率可配置）
- [ ] 验证三角波与外部触发结合（频率 = 触发频率 / 幅值×2）
- [ ] 验证 DMA + 定时器触发实现任意波形
- [ ] 验证波形输出频率精度

### 4. DMA 模式

**测试要点：**
- [ ] 验证 DMA 循环模式（连续输出预定义波形）
- [ ] 验证 DMA 缓冲区大小（数据点数量）
- [ ] 验证 DMA 半传输中断（双缓冲切换）
- [ ] 验证 DMA 传输完成中断
- [ ] 验证 DMA 下溢错误（传输跟不上触发频率）

## 精度测试

| 参数 | 测试方法 | 典型值 |
|------|---------|--------|
| INL（积分非线性） | 数字量递增，测量输出 | ±4 LSB |
| DNL（微分非线性） | 相邻码测量 | ±1 LSB |
| Offset（偏移误差） | 数字量 = 0 | ±10 mV |
| Gain（增益误差） | 数字量 = 满量程 | ±0.5% |
| 建立时间 | 满量程跳变 | 3~6 μs |
| 输出噪声 | 固定码输出，测量纹波 | < 100 μV |

## 边界条件测试

| 测试项 | 边界值 | 预期结果 |
|--------|--------|---------|
| 输出码值 | 0x000 | 输出 ≈ 0V |
| 输出码值 | 0xFFF | 输出 ≈ VREF+ |
| 负载电阻 | 无负载（仅示波器） | 输出正常 |
| 负载电阻 | 最小负载（最大电流） | 输出不跌落 |
| 输出缓冲 | 使能 vs 禁用 | 驱动能力差异 |
| 参考电压 | VREF+ = VDDA | 满量程 = VDDA |

## 常见缺陷

1. **输出缓冲未使能**：驱动大负载时输出电压跌落
2. **建立时间不足**：触发频率过高，输出未达到稳定值就更新
3. **DMA 下溢**：DMA 传输速度跟不上触发频率，波形断续
4. **参考电压噪声**：VREF+ 噪声直接导致输出噪声
5. **代码-电压非单调性**：DNL > 1 LSB 导致输出跳变
6. **双通道同步问题**：两通道更新时间不一致
