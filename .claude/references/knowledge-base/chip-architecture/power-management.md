# MCU 电源管理系统 — 验证指南

车规 MCU 的电源管理直接影响功耗、EMC、启动时间和功能安全。现代车规 MCU 通常支持多种低功耗模式，以应对不同的应用场景（如驻车监控、钥匙检测等）。

## 电源架构

### 1. 电源域划分

典型车规 MCU 划分多个电源域：

| 电源域 | 内容 | 可独立关闭 | 备注 |
|--------|------|-----------|------|
| 核心域（VDD） | CPU、SRAM、Cache | No | 系统核心 |
| 外设域（VDDPeriph） | GPIO、UART、SPI、I2C | Yes | 按外设分组 |
| I/O 域（VDDIO） | GPIO 输入输出缓冲 | Yes | 部分引脚可独立 |
| 模拟域（VDDA） | ADC、DAC、比较器 | Yes | 需稳定后使用 |
| 备份域（VBackup） | RTC、备份寄存器 | No | 由电池供电 |
| USB 域（VDDUSB） | USB PHY | Yes | 仅带 USB 的 MCU |
| Flash 域（VDDFlash） | Flash 读写电路 | Yes | 部分支持 |

**测试要点：**
- [ ] 验证各电源域的上电时序（模拟域必须在数字域之后上电）
- [ ] 验证各电源域的独立开关（关闭后功耗下降）
- [ ] 验证电源域关闭后外设寄存器的状态（保留/复位）
- [ ] 验证电源域重新上电后的初始化要求

### 2. 低功耗模式

| 模式 | CPU | 主时钟 | 外设 | SRAM | 唤醒时间 | 典型功耗 |
|------|-----|--------|------|------|---------|---------|
| Run | 运行 | 全速 | 全部 | 保持 | - | 10~100mA |
| Sleep | 停止 | 全速 | 全部 | 保持 | 立即 | ~90% Run |
| Deep-Sleep | 停止 | 部分停止 | 部分 | 保持 | 10~100μs | ~10% Run |
| Stop | 停止 | 停止 | 部分 | 保持 | 1~10ms | ~1% Run |
| Standby | 停止 | 停止 | 停止 | 丢失 | 10~100ms | ~0.1% Run |

**测试要点：**
- [ ] 验证各模式进入/退出的正确性
- [ ] 验证唤醒源（GPIO、RTC、CAN/LIN 报文、外部中断）
- [ ] 验证唤醒后的时钟恢复（重新配置 PLL）
- [ ] 验证各模式下的功耗（使用精密电流表测量）
- [ ] 验证模式切换时的毛刺（电源波动）

### 3. 唤醒源

| 唤醒源 | Sleep | Deep-Sleep | Stop | Standby | 备注 |
|--------|-------|-----------|------|---------|------|
| 外部中断（EXTI） | Yes | Yes | Yes | Yes | 需配置为唤醒引脚 |
| RTC 闹钟 | Yes | Yes | Yes | Yes | 低功耗时钟保持运行 |
| 看门狗（IWDG） | Yes | Yes | No | No | 独立时钟 |
| CAN 报文 | Yes | Yes | Yes | No | 需 CAN 时钟保持 |
| LIN 报文 | Yes | Yes | Yes | No | 需 LIN 时钟保持 |
| UART 接收 | Yes | Yes | No | No | 需 UART 时钟保持 |
| GPIO 电平变化 | Yes | Yes | Yes | Yes | 需配置为唤醒引脚 |

**测试要点：**
- [ ] 验证每个唤醒源在每种模式下的有效性
- [ ] 验证多个唤醒源同时触发（优先级处理）
- [ ] 验证唤醒后的中断处理（唤醒中断是否丢失）
- [ ] 验证虚假唤醒（噪声导致的误唤醒）

## 电源监控

### 1. POR（Power-On Reset）

**关键参数：**
- 上升沿阈值：通常 1.2~1.5V
- 下降沿阈值：通常 1.0~1.3V（迟滞 200mV）
- 上电斜率要求：dV/dt > 最小值（通常 10mV/ms）

**测试要点：**
- [ ] 验证 POR 阈值（缓慢上电和掉电）
- [ ] 验证上电斜率限制（过慢导致 POR 反复触发）
- [ ] 验证 POR 后的启动时序（时钟稳定 → 启动代码）

### 2. BOR（Brown-Out Reset）

**关键参数：**
- 多级阈值：Level 0（2.0V）、Level 1（2.2V）、Level 2（2.4V）、Level 3（2.6V）
- 迟滞：通常 100~200mV
- 响应时间：通常 1~10μs

**测试要点：**
- [ ] 验证各级 BOR 阈值（使用可变电源缓慢降压）
- [ ] 验证 BOR 迟滞（防止在阈值附近振荡）
- [ ] 验证 BOR 触发后的复位行为
- [ ] 验证 BOR 中断模式（提前预警，不立即复位）

### 3. PVD（Programmable Voltage Detector）

**关键参数：**
- 可配置阈值：多级（如 2.1V/2.3V/2.5V/2.7V/2.9V/3.1V）
- 用途：早期预警（在 BOR 之前触发中断）

**测试要点：**
- [ ] 验证各阈值配置
- [ ] 验证 PVD 中断触发
- [ ] 验证 PVD 与 BOR 的协同（PVD 预警 → BOR 复位）

## 功能安全要求

### 1. 电源监控安全
- **独立电源监控**：使用独立于 CPU 的硬件监控电源
- **多级预警**：PVD 预警 → BOR 复位 → 安全状态
- **电源故障记录**：记录电源故障类型和时间

### 2. 低功耗模式安全
- **关键外设保持**：安全相关外设（看门狗、时钟监控）在低功耗模式下保持运行
- **唤醒后自检**：从低功耗模式唤醒后执行部分 BIST
- **安全状态保持**：Standby 模式下安全状态信息保存在备份域

### 3. 功耗预算验证
- **最大功耗**：所有外设全速运行时的功耗（散热设计依据）
- **典型功耗**：正常工况下的功耗
- **静态功耗**：所有时钟停止时的漏电流
