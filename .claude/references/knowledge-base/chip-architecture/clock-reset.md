# MCU 时钟与复位系统 — 验证指南

时钟和复位是 MCU 的"心跳"和"生命线"。车规 MCU 对时钟的稳定性、复位的可靠性有极高要求，任何时钟失效或复位异常都可能导致功能安全事件。

## 时钟系统

### 1. 时钟源

| 时钟源 | 频率范围 | 精度 | 用途 | 特性 |
|--------|---------|------|------|------|
| 外部晶振（HSE/XTAL） | 4 ~ 50MHz | ±10~50ppm | 系统主时钟 | 高精度，需外部晶振 |
| 内部 RC（HSI/IRC） | 8 ~ 64MHz | ±1~3% | 备份/快速启动 | 无需外部器件，精度低 |
| 外部时钟（HSE_BYP） | 1 ~ 50MHz | 取决于输入 | 外部有源晶振 | 可直接输入方波 |
| 低速晶振（LSE） | 32.768kHz | ±20ppm | RTC、看门狗 | 低功耗，高精度 |
| 低速内部 RC（LSI） | 32kHz | ±5~10% | 看门狗、RTC 备份 | 低功耗，精度低 |
| PLL | 几十 ~ 几百MHz | 取决于参考 | 高频系统时钟 | 可倍频、分频 |

### 2. 时钟树结构

典型车规 MCU 时钟树：
```
XTAL/IRC → PLL → 系统时钟 (SYSCLK)
                 → AHB 总线时钟 (HCLK)
                 → APB1/APB2 外设时钟 (PCLK1/PCLK2)
                 → CPU 核心时钟 (FCLK)
                 → Flash 时钟
                 → ADC/DAC 时钟
                 → 定时器时钟
                 → 通信外设时钟（CAN/LIN/SPI 等）
```

**测试要点：**
- [ ] 验证所有时钟源的起振时间（HSE 通常 2~5ms，LSE 可达 1s）
- [ ] 验证 PLL 锁定时间（Lock Time）
- [ ] 验证时钟分频器的正确性（1/2/4/8/16...）
- [ ] 验证时钟切换（IRC → HSE → PLL）的时序要求
- [ ] 验证时钟门控（Clock Gating）的功耗节省
- [ ] 验证外设时钟使能/禁用（不影响其他外设）

### 3. 时钟安全监控

**CSS（Clock Security System）：**
- 监测 HSE 是否失效
- HSE 失效时自动切换到 HSI
- 触发中断/复位

**测试要点：**
- [ ] 模拟 HSE 失效（断开晶振或注入噪声），验证 CSS 检测
- [ ] 验证 HSE 失效后的自动切换（→ HSI）
- [ ] 验证 CSS 故障后的中断/复位行为
- [ ] 验证 PLL 失锁检测（PLL Lock Loss）
- [ ] 验证时钟完整性检查（Clock Integrity Check）

**常见缺陷：**
- 时钟切换时未等待新时钟稳定，导致系统死锁
- PLL 配置超出 VCO 频率范围，导致无法锁定
- 外设时钟未使能就访问寄存器，导致总线挂死
- Flash 等待周期与时钟频率不匹配，导致取指令错误

## 复位系统

### 1. 复位源

| 复位源 | 触发条件 | 复位范围 | 特性 |
|--------|---------|---------|------|
| POR（Power-On Reset） | 电源上电 | 全芯片 | 上电时序控制 |
| BOR（Brown-Out Reset） | 电源电压跌落 | 全芯片 | 可配置阈值 |
| 外部复位（NRST） | 外部引脚拉低 | 全芯片 | 手动复位 |
| WWDG（Window Watchdog） | 喂狗超时或过早 | 全芯片 | 窗口限制 |
| IWDG（Independent Watchdog） | 喂狗超时 | 全芯片 | 独立时钟 |
| 软件复位（SYSRESETREQ） | 软件写寄存器 | 全芯片 | 调试/OTA |
| 欠压复位（LVDR） | 低电压检测 | 全芯片 | 可配置 |

### 2. 复位域

车规 MCU 通常划分多个复位域：
- **系统复位域**：CPU + 大部分外设
- **外设复位域**：独立外设可单独复位
- **电源域复位**：不同电源域独立复位

**测试要点：**
- [ ] 验证各复位源触发后系统正确复位
- [ ] 验证复位后的默认寄存器值（与 RM 对比）
- [ ] 验证外设独立复位（不影响其他外设）
- [ ] 验证复位后的启动时间（从复位到 main()）
- [ ] 验证复位标志位（区分复位源）

### 3. 上电时序（Power-Up Sequence）

```
VDD 上电 → POR 释放 → BOR 检测 → 时钟稳定 → 启动代码执行
   ↑           ↑          ↑           ↑              ↑
 0.9V        1.2V       1.5V       2~5ms        10~100ms
```

**测试要点：**
- [ ] 验证 POR 阈值（上升沿和下降沿的迟滞）
- [ ] 验证 BOR 阈值（多级阈值：2.0V/2.2V/2.4V/2.6V）
- [ ] 验证上电斜率要求（dV/dt > 最小值）
- [ ] 验证掉电时的安全行为（BOR 触发复位）

**常见缺陷：**
- 电源上电斜率过慢，POR 反复触发
- 看门狗在初始化完成前超时，导致复位循环
- 软件复位后未清除复位标志，导致错误判断复位源
- 欠压复位阈值设置过高，正常运行时误触发

## 低功耗模式下的时钟/复位

| 模式 | 系统时钟 | 外设时钟 | 复位行为 |
|------|---------|---------|---------|
| Sleep | CPU 停止 | 外设运行 | WFI/WFE 唤醒 |
| Deep-Sleep | CPU 停止 | 部分外设停止 | 中断唤醒 |
| Standby | 全部停止 | 全部停止 | 特定唤醒源复位启动 |

**测试要点：**
- [ ] 验证 Sleep 模式下的中断唤醒时间
- [ ] 验证 Deep-Sleep 模式下的外设状态保持
- [ ] 验证 Standby 模式下的功耗（μA 级）
- [ ] 验证唤醒后的时钟恢复（重新使能 PLL）
- [ ] 验证 RTC 在低功耗模式下的持续运行
