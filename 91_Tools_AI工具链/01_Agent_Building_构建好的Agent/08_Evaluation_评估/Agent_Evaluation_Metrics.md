# Agent 评估指标与方法

> 如何判断一个 Agent 好不好？有哪些可量化的指标？

## 核心问题

Agent 的质量应该从哪些维度评估？

## 结论

Agent 评估应从 **正确性、效率、可解释性、安全性、用户体验** 五个维度展开。

---

## 1. 正确性（Correctness）

- 任务是否按预期完成？
- 输出是否符合规范？
- 是否引入了错误？

评估方法：人工检查、单元测试、回归测试、基准任务集。

## 2. 效率（Efficiency）

- 完成任务用了多少步？
- 调用了多少次工具？
- 消耗了多少 Token？

评估方法：步骤计数、Token 用量统计、时间测量。

## 3. 可解释性（Explainability）

- Agent 是否说明了决策原因？
- 输出是否结构化？
- 是否能追溯执行路径？

评估方法：日志审查、输出格式检查。

## 4. 安全性（Safety）

- 是否执行了未授权操作？
- 是否泄露了敏感信息？
- 是否有明确的权限边界？

评估方法：红队测试、权限审查、敏感信息扫描。

## 5. 用户体验（UX）

- 是否过度打断用户？
- 是否在合适时机寻求帮助？
- 输出是否易于理解？

评估方法：用户反馈、会话满意度评分。

## 评估流程

```text
定义任务 → 收集输入 → 运行 Agent → 记录轨迹 → 多维打分 → 定位问题 → 迭代改进
```
