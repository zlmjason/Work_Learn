# 《SoC设计基础教程——系统架构》目的驱动型精读路线

> 按 `purpose-driven-book-study` 技能建立。原书素材：[[../../../99_Attachments_附件/IC_Design_芯片设计/SoC设计基础教程_系统架构/full.md]]（MinerU 解析，5133 行）。

## 1. 学习目的

- **当前工作主线**：车规 MCU 全栈（AURIX TC3xx / NXP S32E2 / Cortex-M7 / AUTOSAR）
- **希望获得的能力**：SoC 系统架构全景 + 读芯片手册（TRM/UM）的"元能力"——手册每个章节能映射回本书框架
- **需要解决的具体问题**：WCET 与时序确定性、cache 维护与 DMA 一致性、总线带宽预算、存储选型（PFLASH/DFLASH/EEPROM 仿真）、SafeSPI 等外设协议评估
- **暂不解决的问题**：SoC 设计实现细节（姊妹篇《技术实现》未入库）；功能安全专门内容（ISO 26262 靠既有体系，本书不覆盖）

## 2. 全书定位

- **作者意图**：张庆（电子工业出版社 2025.1 第 1 版）。由企业内部技术培训讲义改编，目标是帮"只懂单个 IP 的工程师"建立 SoC 全系统视角、弥合前后端术语鸿沟
- **中心模型**：① 静态组成：SoC = 处理器 + 存储 + 互连 + 外设 + 芯片管理的层次组合；② 动态流程：规格 → 架构 → 集成验证 → 综合 → DFT → 后端签核
- **目标读者**：SoC 设计工程师、芯片规划/项目管理人员（先修：电路与电子技术基础）
- **证据类型**：经验型（培训实践），非学术推导型——结论按"经验法则"对待，具体参数回原厂手册验证
- **适用范围**：基本概念、方法、设计规范；偏通用 SoC 视角
- **不适用/限制**：刻意剪裁深度（复杂场景在《高级教程》，已在库）；不讲 EDA 工具操作；姊妹篇《技术实现》未入库 → "怎么实现"层面有空缺；车规功能安全（锁步/ASIL）几乎不涉及，需自行桥接
